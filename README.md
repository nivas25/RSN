## 🌐 Overview
This is the official portfolio of **Reddy Sai Nivas**, designed as an ultra-premium, interactive 3D web experience. Built with **Astro**, **Three.js**, and **GSAP**, this project abandons traditional web navigation in favor of a morphing kinetic 3D cube that seamlessly transitions between pages.

It is heavily optimized, entirely Serverless-ready, and designed to provide a world-class user experience.

## ✨ Features
- **Kinetic 3D Navigation:** A morphing WebGL cube (via Three.js) controls all page routing.
- **Serverless Contact System:** Integrated with the Resend API and Vercel Edge Functions for a highly secure, backend-powered contact form.
- **Micro-Interactions:** Smooth GSAP-powered reveals, depth-of-field scrolling, and dynamic magnetic cursors.
- **Zero-JavaScript Degradation:** Fully built with Astro's Islands architecture, shipping near-zero JS where possible.
- **ImageKit Optimizations:** All media is dynamically sized and heavily compressed at the edge.

## 🚀 Tech Stack
- **Framework:** Astro 5.0 (Hybrid Serverless output)
- **3D Engine:** Three.js
- **Animations:** GSAP & OGL
- **Styling:** Vanilla CSS (Zero dependencies, pure performance)
- **Deployment:** Vercel (Edge Functions for `/api/contact`)
- **Email Delivery:** Resend SDK

## 💻 Local Setup

1. **Clone & Install**
   ```bash
   git clone https://github.com/nivas25/RSN.git
   cd RSN
   npm install
   ```

2. **Environment Variables**
   Create a `.env` file at the root of the project and add your Resend API key to test the contact form:
   ```env
   RESEND_API_KEY=re_your_api_key_here
   ```

3. **Start Development Server**
   ```bash
   npm run dev
   ```
   Navigate to `http://localhost:4321` to view the local site.
